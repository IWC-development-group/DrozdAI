# DrozdAI API specification

Here represented an API used by the model's server.

### (GET) Status querying:

**Request:**
```
/status
```

**Response:**
If the model is currently generating an answer:
```json
{
	"busy": true
}
```

Else:
```json
{
	"busy": false
}
```

### (GET) Hosted model info querying:

**Request:**
```
/about
```

**Response:**
```json
{
	"model_name": "name of the model",
	"model_description": "model description"
}
```

### (GET) Send a prompt

**Request:**
```
/prompt?prompt=[text_message]&temperature=[float_value]&length=[max_new_tokens]
```

`length` - an argument that defines maximum count of tokens that will be generated by the model.

**Response:**

If no error occured:
```json
{
	"error": null,
	"message": "model's answer"
}
```

If the model is busy:
```json
{
	"error": "MODEL_IS_BUSY",
	"retry_after": [retry interval]
}
```

Else:
```json
{
	"error": "error message",
	"message": ""
}
